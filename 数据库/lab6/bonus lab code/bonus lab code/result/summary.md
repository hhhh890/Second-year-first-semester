# Verification Run 2026-06-09

This directory records a fresh local verification run. Files under `logs/` are raw command outputs captured from the real test commands, mostly with `tee`, plus copies of TPC-C driver/server logs generated by the benchmark scripts.

## What Is Raw Output

- `logs/01_build.log`: build output for `rmdb`, `tpcc_loader`, `tpcc_driver`, and B+ tree tests.
- `logs/02_bplus_insert.log`: raw output of `./build/bin/b_plus_tree_insert_test`.
- `logs/03_bplus_delete.log`: raw output of `./build/bin/b_plus_tree_delete_test`.
- `logs/04_bplus_concurrent.log`: raw output of `./build/bin/b_plus_tree_concurrent_test`.
- `logs/05_transaction_test.log`: raw output of `python3 transaction_test.py`.
- `logs/06_transaction_test_bonus.log`: raw output of `python3 transaction_test_bonus.py`.
- `logs/07_concurrency_test.log`: raw output of `python3 concurrency_test.py`.
- `logs/08_concurrency_test_bonus.log`: raw output of `python3 concurrency_test_bonus.py`.
- `logs/10_tpcc_s10_console.log`: raw console output of `bash scripts/02_run_s10_t4_d60.sh`.
- `logs/10_tpcc_s10_driver.log`: benchmark driver log copied from `build/dbroot/driver_s10_t4_d60.log`.
- `logs/10_tpcc_s10_server.log`: database server log copied from `build/dbroot/server_s10_t4_d60.log`.
- `logs/11_tpcc_s1_console.log`: raw console output of `bash scripts/03_run_s1_t4_d300.sh`.

## Commands Used

From the repository root:

```bash
cmake --build build --target rmdb tpcc_loader tpcc_driver b_plus_tree_insert_test b_plus_tree_delete_test b_plus_tree_concurrent_test -j4
./build/bin/b_plus_tree_insert_test
./build/bin/b_plus_tree_delete_test
./build/bin/b_plus_tree_concurrent_test
cmake --build build --target rmdb tpcc_loader tpcc_driver -j4
bash scripts/02_run_s10_t4_d60.sh
bash scripts/03_run_s1_t4_d300.sh
```

Transaction tests were run from `src/test/transaction` because the scripts use relative paths:

```bash
python3 transaction_test.py
python3 transaction_test_bonus.py
```

Concurrency tests were run from `src/test/concurrency` because the scripts use relative paths:

```bash
python3 concurrency_test.py
python3 concurrency_test_bonus.py
```
